# Attention 分子与分母小节改写设计

## 目标

扩写 `Week4_Attention与FlashAttention完整学习资料.md` 第 23 节，让初学者理解普通 Attention 为什么能写成“向量分子除以标量分母”，以及为什么分块可以分批累加、却不能在每个 tile 内提前完成除法。

## 修改范围

只重写第 23 节。第 22 节已有的错误局部 softmax 示例保持不变；第 24 节及之后的 `m/l/O_acc`、数值稳定性与 CUDA 内容保持不变。

## 教学顺序

1. 从 `p_j=softmax(score)_j` 和 `O=Σp_jV_j` 开始；
2. 把 softmax 定义代入加权和，逐行推导共同分母；
3. 解释分母是标量，分子是与单个 `V_j` 同维度的向量；
4. 沿用 scores `[2,1,4,3]` 和二维 values，把输入分为 tile A、tile B；
5. 分别计算两个 tile 的未归一化局部分母和局部分子；
6. 把局部分子相加、局部分母相加，复原全局 Attention；
7. 用“加法可以分批，除法不能提前”总结；
8. 说明该方法数学正确但直接计算 `exp(score)` 不稳定，引向第 24 节。

## 表达约束

- 不提前使用尚未解释的 `m/l/O_acc`；
- 不重复第 22 节的局部 softmax 错误数值；
- 数字示例必须与全文同一组 scores 和 values 一致；
- 同时给出符号表达与近似数值，但避免无助于理解的过长小数；
- 明确“向量除以标量”表示向量每个分量都除以该标量。

## 验收标准
