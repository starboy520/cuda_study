## 0. 先看全景：训练到底在干什么

一句话：**训练 = 反复微调模型的参数，让它的预测越来越接近正确答案。**

拆成一个循环（记住这张图，后面全是在讲它的每一步）：

```
        ┌─────────────────────────────────────────┐
        │  1. forward：用当前参数算出预测            │
        │  2. loss：预测和真实答案差多少（一个数）   │
        │  3. backward：算每个参数该往哪调（梯度）   │
        │  4. update：参数朝"让 loss 变小"的方向挪一点│
        └──────────────────┬──────────────────────┘
                           │ 重复几万次
                           ▼
                   参数越来越好，loss 越来越小
```

- **forward（前向）**：你已经很熟——就是推理，输入 → 一堆运算 → 输出。
- **loss（损失）**：一个数，衡量"错得多严重"。越小越好。
- **backward（反向）**：训练特有的新东西，算"每个参数动一点，loss 会变多少"。
- **update（更新）**：根据 backward 的结果调参数。

**训练比推理多的，就是 backward + update 这条回路。** 第一卷就是把这条回路讲清楚。

## 1. 模型 = 一个带参数的函数

别把"模型"想得很玄。它就是一个**函数**，里面有一些可以调的**参数（parameter）**。

最简单的模型（后面全程用它举例）：

$$
\hat{y} = w \cdot x + b
$$

- `x`：输入（已知，比如一个特征）
- `w`、`b`：**参数**（要训练调整的东西，w 叫权重 weight，b 叫偏置 bias）
- `ŷ`（读作 y-hat）：模型的**预测**

**关键区分**：
- `x` 是数据，**给定不变**
- `w`、`b` 是参数，**训练时不断调整**

**类比**：`ŷ = w·x + b` 就像一台有两个旋钮的机器。`x` 是原料，`w`、`b` 是两个旋钮。训练就是"不停拧旋钮，让机器输出越来越对"。

> **一句话记忆**：模型就是个带旋钮（参数 w/b）的函数。训练 = 拧旋钮让输出变对。

**CUDA 连接**：真实模型里 `w` 是巨大的矩阵，`w·x` 就是你写的 GEMM/GEMV。一个 LLM 有几十亿个"旋钮"。

---

## 2. loss：把"错多少"变成一个数

要"让预测变对"，先得**量化"错多少"**。这就是损失函数。

最常用的一种——**平方误差**：

$$
L = (\hat{y} - y_{true})^2
$$

`y_true` 是真实答案。预测和答案差得越远，`L` 越大。平方是为了：① 让正负误差都变正 ② 差得越远惩罚越狠。

### 数字例子

设 `x=2, y_true=5`，当前 `w=1, b=0`：

```
ŷ = w·x + b = 1×2 + 0 = 2      ← 预测
误差 e = ŷ - y_true = 2 - 5 = -3
L = e² = (-3)² = 9             ← 损失
```

损失 9，说明还差得远（完美的话 L=0）。我们的目标：**调 w、b，让 L 变小**。

> **一句话记忆**：loss 是一个数，衡量预测错多严重。训练目标就是把这个数降到最小。

---

## 3. 导数：不是咒语，就是"斜率"

现在核心问题来了：**该往哪个方向调 w、b，才能让 L 变小？** 答案藏在"导数"里。

### 3.1 导数 = 局部斜率 = "输入动一点，输出动多少"

导数听着吓人，其实就是**斜率**：

> 某个变量**变化一点点**，函数值**变化多少**，两者的比值。

$$
\frac{\partial L}{\partial w} = \text{"w 变化 1，L 大约变化多少"}
$$

**类比**：你站在山坡上。
- 导数 = **脚下坡的陡峭程度和方向**
- 导数为正 = 往这个方向走是**上坡**（L 变大）
- 导数为负 = 往这个方向走是**下坡**（L 变小）
- 导数绝对值大 = 坡很陡（变化剧烈）

训练要让 L 变小 = **下山**。所以我们要朝"下坡"方向走——也就是**导数的反方向**。

> **一句话记忆**：导数 = 局部斜率 = "变量动一点，函数动多少"。正=上坡，负=下坡，大=陡。

### 3.2 偏导数：多个参数时，一次只看一个

我们的 L 同时依赖 `w` 和 `b`。想知道"只调 w 会怎样"，就**固定 b、只动 w**，算出的斜率叫**偏导数（partial derivative）**：

$$
\frac{\partial L}{\partial w}：\text{固定 b，w 动一点，L 动多少}
$$
$$
\frac{\partial L}{\partial b}：\text{固定 w，b 动一点，L 动多少}
$$

**类比**：山坡是二维的（w 方向、b 方向）。偏导就是"只沿东西方向（w）看坡多陡"和"只沿南北方向（b）看坡多陡"，分开量。

### 3.3 梯度：把所有偏导打包成一个向量

把 L 对**所有参数**的偏导收集起来，就是**梯度（gradient）**：

$$
\nabla L = \left[\frac{\partial L}{\partial w},\ \frac{\partial L}{\partial b}\right]
$$

梯度是个**向量**，它有个重要性质：

> **梯度指向"L 上升最快"的方向。**

所以要让 L 下降，就朝**梯度的反方向**走。这就是整个训练的核心动作。

**类比**：站在山坡上，梯度是一个箭头，指着"最陡的上坡方向"。想最快下山，就朝箭头**反方向**走。

> **一句话记忆**：偏导 = 只动一个参数看斜率；梯度 = 所有偏导打包成的向量，指向 L 上升最快的方向；训练朝它反方向走 = 下山。

---

## 4. 链式法则与反向传播（第一卷最难，重点）

上面说要算梯度 `∂L/∂w`，但有个问题：**w 不是直接算出 L 的，中间隔了好几步**：

$$
w \longrightarrow \hat{y} \longrightarrow e \longrightarrow L
$$

（w 先影响预测 ŷ，ŷ 影响误差 e，e 影响损失 L）

**问题**：隔着好几步，w 动一点，L 到底动多少？—— 这就是**链式法则**要解决的。

### 4.1 每一步的"局部斜率"

先把每一小段的局部导数（"这段输入动一点，这段输出动多少"）列出来：

| 这一段 | 公式 | 局部导数 | 意思 |
|--------|------|---------|------|
| w → ŷ | `ŷ = wx+b` | `∂ŷ/∂w = x` | w 变 1，ŷ 变 x |
| ŷ → e | `e = ŷ - y` | `∂e/∂ŷ = 1` | ŷ 变 1，e 变 1 |
| e → L | `L = e²` | `∂L/∂e = 2e` | e 变 1，L 变 2e |

（这些局部导数都是基本求导规则，记不住没关系，理解"每段的放大倍数"就行。）

### 4.2 链式法则 = 沿路把局部斜率相乘

**链式法则**说：w 对 L 的总影响 = **沿路径把每一段的局部导数乘起来**。

$$
\frac{\partial L}{\partial w} = \underbrace{\frac{\partial L}{\partial e}}_{2e} \times \underbrace{\frac{\partial e}{\partial \hat{y}}}_{1} \times \underbrace{\frac{\partial \hat{y}}{\partial w}}_{x} = 2e \cdot 1 \cdot x = 2ex
$$

**类比：齿轮传动**。

```
w ──[×x]──→ ŷ ──[×1]──→ e ──[×2e]──→ L
   放大 x     放大 1     放大 2e
```

第一个齿轮转 1 圈，经过三段传动（×x、×1、×2e），最后一个齿轮转 `2e·1·x` 圈。**总放大倍数 = 各段倍数连乘**。

**为什么是相乘不是相加？** 因为影响是**层层传递、逐级放大**的：w 变 1 → ŷ 变 x（不是变 1）→ e 也变 x → L 变 `x × 2e`。每一段都在上一段的基础上再放大，所以连乘。

### 4.3 代入数字

用前面的例子 `e = -3, x = 2`：

$$
\frac{\partial L}{\partial w} = 2ex = 2\times(-3)\times 2 = -12
$$
$$
\frac{\partial L}{\partial b} = 2e \cdot 1 = 2\times(-3) = -6
$$

（b 那条链是 `b → ŷ → e → L`，`∂ŷ/∂b = 1`，所以比 w 少乘一个 x）

**梯度 = [-12, -6]**。

### 4.4 这个"从后往前算"的过程就是反向传播

注意计算方向：我们从**最后的 L 出发，一段段往回乘**局部导数，推回到 w、b。这个"从损失反向逐段算梯度"的过程，就叫**反向传播（backpropagation，简称 backprop）**。

> 文档强调的一句话："反向传播不是另一套数学，它只是高效复用链式法则。" —— backprop = 把链式法则沿计算图从后往前系统地跑一遍，没有新公式。

**为什么要反向算（而不是正向）？** 因为很多参数**共享同一条后半段路径**。反向时 `∂L/∂e = 2e` 这段只算一次，然后分别乘各自的前半段（w 乘 x、b 乘 1）。深网络里几十亿参数共享大量中间路径，反向复用能省巨量计算——这就是 backprop 高效的原因。

> **一句话记忆**：w 隔着几步影响 L，总影响 = 沿路局部导数**连乘**（齿轮传动，倍数相乘）。从 L 往回逐段乘的过程 = 反向传播，它只是系统地复用链式法则，且能复用共享路径省算力。

**CUDA 连接**：前向是一堆 GEMM；反向也是一堆 GEMM（每层的局部导数是矩阵），而且反向的计算量约是前向的 **2 倍**。这就是训练比推理贵的核心原因之一。

## 5. SGD：用梯度更新参数

有了梯度（方向），就能更新参数了。最基本的方法叫 **SGD（随机梯度下降，stochastic gradient descent）**：

$$
w \leftarrow w - \eta \frac{\partial L}{\partial w}, \qquad b \leftarrow b - \eta \frac{\partial L}{\partial b}
$$

- `η`（读作 eta）：**学习率（learning rate）**，控制每步走多远（步长）
- 注意那个**减号**：朝梯度**反方向**走（下山），因为梯度指向上山

### 数字例子（接上面，η = 0.1）

梯度是 `[-12, -6]`：

$$
w \leftarrow 1 - 0.1\times(-12) = 1 + 1.2 = 2.2
$$
$$
b \leftarrow 0 - 0.1\times(-6) = 0 + 0.6 = 0.6
$$

（`- η·(负梯度)` = `+`，所以 w、b 都变大——正如梯度指示的下山方向）

### 验证 loss 真的降了

新参数 `w=2.2, b=0.6`，重算：

```
ŷ = 2.2×2 + 0.6 = 5.0
e = 5.0 - 5 = 0
L = 0² = 0        ← 损失从 9 → 0！
```

这个例子**一步就命中**（因为太简单）。真实训练不会这么快，要反复几万步慢慢逼近。而且**学习率太大会越过最低点甚至发散**（步子迈太大，一脚跨过山谷到对面更高处）。

> **一句话记忆**：SGD = `参数 -= 学习率 × 梯度`。减号朝反方向下山，学习率控制步长。太大发散，太小太慢。

## 6. 完整训练循环（把 1-5 串起来）

现在把整条链串成代码逻辑（伪代码）：

```python
w, b = 1.0, 0.0            # 初始化参数（随便给）
lr = 0.1                   # 学习率
for step in range(10000):  # 反复迭代
    # 1. forward：算预测
    y_hat = w * x + b
    # 2. loss
    e = y_hat - y_true
    L = e * e
    # 3. backward：链式法则算梯度
    dL_dw = 2 * e * x
    dL_db = 2 * e
    # 4. update：SGD
    w = w - lr * dL_dw
    b = b - lr * dL_db
    # L 会一步步变小
```

这就是**所有训练的骨架**。大模型训练只是把 `w·x+b` 换成几十层 Transformer、把标量换成大矩阵，但**forward → loss → backward → update 这四步一模一样**。

> **一句话记忆**：训练 = 循环{ 前向算预测 → 算 loss → 反向算梯度 → SGD 更新 }。大模型只是把里面的函数换大，骨架不变。

## 7. 梯度检查：怎么知道梯度没算错

手推链式法则容易写错。有个笨但可靠的验证法——**中心有限差分（central finite difference）**：

$$
\frac{\partial L}{\partial w} \approx \frac{L(w+h,\ b) - L(w-h,\ b)}{2h}
$$

思路很直白：**直接把 w 挪一小步 `h`（比如 1e-6），看 L 变了多少**，用"变化量 / 步长"近似斜率。这是导数的原始定义。

- 用它算出的近似梯度，和你链式法则推的梯度对比，两者接近 → 推导对了
- 它**很慢**（每个参数要多做两次 forward），只用于**小例子调试**，不用于真实训练
- `h` 不是越小越好——太小会被浮点舍入误差污染

> **一句话记忆**：梯度检查 = 直接挪参数一小步看 loss 变多少（`ΔL/2h`），用来验证手推的梯度对不对。慢，只调试用。

**CUDA 连接**：这和你 GEMV/attention 里"用 CPU 参考对拍 GPU 结果"是同一个精神——都是"用一个慢但可靠的方法验证快方法的正确性"。

## 8. 从标量到矩阵：Linear 层

前面都是一个数 `w`。真实模型一次处理**一批样本、每个样本多个特征**，参数变成矩阵。这就是 **Linear 层（线性层 / 全连接层）**：

$$
Y = XW + b
$$

形状（记住这张表，后面处处用）：

| 张量 | 含义 | shape |
|------|------|-------|
| `X` | 一批输入 | `[B, I]` |
| `W` | 权重矩阵 | `[I, O]` |
| `b` | 偏置（每个输出通道一个） | `[O]` |
| `Y` | 一批输出 | `[B, O]` |

- `B` = batch size（一批多少样本）
- `I` = 输入特征数，`O` = 输出特征数
- `b` 加到每一行，这种自动扩展叫**广播（broadcasting）**

**这就是你写的 GEMM！** `Y = XW` 就是矩阵乘。标量的 `ŷ = wx` 只是 `B=I=O=1` 的特例。

### Linear 的反向（了解即可）

反向时，上游传来 `dY = ∂L/∂Y`（shape `[B,O]`），Linear 算三个梯度：

$$
dX = dY\, W^T \quad [B,O][O,I]\to[B,I]  \quad(\text{传给更前面的层})
$$
$$
dW = X^T dY \quad [I,B][B,O]\to[I,O]  \quad(\text{更新 W 用})
$$
$$
db = \sum_{n=1}^{B} dY_n \quad [B,O]\to[O]  \quad(\text{更新 b 用})
$$

注意 `db` 沿 batch 维**求和**——因为同一个 `b` 被一批里所有样本共用，它们的梯度要累加。

**看出规律了吗**：反向也全是矩阵乘（`dY·Wᵀ`、`Xᵀ·dY`）。所以训练 = 前向一堆 GEMM + 反向更多 GEMM。

> **一句话记忆**：Linear 层 `Y=XW+b` 就是 GEMM，标量模型的矩阵版。反向 dX/dW/db 也都是矩阵乘 + 求和，所以训练是"GEMM 的正反两遍"。

## 9. 非线性与 MLP：为什么要 ReLU

如果只堆 Linear（`Linear→Linear→Linear`），数学上**多个线性变换能合并成一个线性变换**，堆再多也等于一层，白搭。所以中间要插**非线性**。

最常用的 **ReLU（修正线性单元）**：

$$
\operatorname{ReLU}(z) = \max(0, z)
$$

就是"负数变 0，正数不变"。它的导数超简单：`z>0` 时是 1，`z<0` 时是 0。**ReLU 的反向 = 上游梯度乘一个 `z>0` 的掩码**（正数位置梯度通过，负数位置梯度归零）。

**两层 MLP（多层感知机）**= Linear + ReLU + Linear：

$$
Z_1 = XW_1 + b_1 \quad\to\quad H = \operatorname{ReLU}(Z_1) \quad\to\quad Y = HW_2 + b_2
$$

这就是你在 LLM 里见过的 MLP（升维 → 激活 → 降维）的最简版。反向按 forward **逆序**走：先对第二个 Linear 求导 → 穿过 ReLU 掩码 → 再对第一个 Linear 求导。每一步都是"接上游梯度 × 自己的局部导数 → 传给更前面"。

> **一句话记忆**：只堆 Linear 等于一层（线性可合并），所以插 ReLU 加非线性。MLP = Linear+ReLU+Linear。反向按前向逆序，逐层"乘局部导数往回传"。

## 10. 训练循环里的六个"计量单位"（易混词）

这几个词经常搞混，一次说清：

| 词 | 含义 | 例子 |
|----|------|------|
| **sample（样本）** | 一条训练数据 `(x, y)` | 一张图 + 它的标签 |
| **batch（批）** | 一起算 loss 和梯度的一组样本 | 100 个样本一批 |
| **batch size** | 一批里的样本数 | 100 |
| **microbatch（微批）** | 显存放不下整批时，实际一次送进 GPU 的更小子批 | 4 个 25 拼成 batch 100 |
| **gradient accumulation（梯度累积）** | 多个 microbatch 依次 backward、梯度**相加**，攒够才更新一次 | 4 次累积 = 1 次有效更新 |
| **step（优化器步）** | 执行**一次参数更新** | 只 forward 不更新，不算 step |
| **epoch（轮次）** | 训练集每个样本大致都被用过一次 | 1000 样本 / batch 100 = 一轮 10 step |

**两个关键坑**：
1. **梯度累积要正确缩放**：想模拟整批的平均梯度，要么每个 microbatch 的 loss 除以累积次数，要么最后梯度除以总样本数。否则梯度偏大。
2. **每次更新后要清零梯度**：很多框架 backward 默认是"把新梯度**加到**已有梯度上"（为了支持累积），所以更新完必须 `zero_grad()`，否则梯度会越滚越大。

> **一句话记忆**：sample→batch→epoch 是数据量级；microbatch + 梯度累积是"显存不够时把大 batch 拆着算再攒梯度"；step = 一次参数更新。切记更新后清零梯度。

## 11. 映射回 CUDA（你的强项，重点连接）

第一卷的所有数学，落到 GPU 上都是你熟悉的东西：

| ML 概念 | CUDA 现实 |
|---------|-----------|
| forward 的 `XW` | GEMM（你写过） |
| decode 单样本的 `wx` | GEMV（你 Week5 写的） |
| backward 的 `dY·Wᵀ`、`Xᵀ·dY` | 更多 GEMM（反向 ≈ 前向 2 倍算力） |
| ReLU / 激活 | 逐元素 kernel（memory-bound） |
| loss、归约 | reduction（你写过） |
| 梯度检查对拍 | 和你 CPU-reference 对拍 GPU 一个道理 |
| 存梯度 + 优化器状态 | 训练显存 ≈ 推理的好几倍（参数 + 梯度 + Adam 动量） |

**核心认知**：训练 = 前向（GEMM/GEMV/norm/激活，你都熟）+ 反向（又一遍 GEMM）+ 更新（逐元素）。你的 CUDA 技能在训练侧**直接复用**，只是多了"反向"这条回路。

---

## 12. 常见误区（避坑）

1. **"导数是高深数学"** → 不是，就是局部斜率（山坡陡峭度）。
2. **"反向传播是另一套算法"** → 不是，只是链式法则从后往前系统跑一遍。
3. **"梯度指向 loss 下降方向"** → 反了！梯度指向**上升**最快方向，所以更新用**减号**朝反方向。
4. **"堆很多 Linear 就更强"** → 不加非线性，多层线性可合并成一层，白堆。必须有 ReLU 之类。
5. **"backward 完直接更新就行"** → 别忘 `zero_grad`，否则梯度累加出错。
6. **"学习率越大学得越快"** → 太大越过最低点甚至发散。

## 13. 自测（合上文档，能答出来就过关）

1. 训练循环的四步是什么？（forward / loss / backward / update）
2. 导数的直觉含义是什么？（局部斜率："变量动一点，函数动多少"）
3. 梯度指向哪个方向？为什么更新用减号？（上升最快方向；减号朝反方向下山）
4. 链式法则为什么是"相乘"？（影响层层传递、逐级放大，各段倍数连乘）
5. 反向传播和链式法则什么关系？（backprop = 系统地从后往前跑链式法则，复用共享路径）
6. Linear 层 `Y=XW+b` 对应哪个 CUDA 算子？（GEMM）
7. 为什么 MLP 中间要 ReLU？（不加非线性，多层线性等于一层）
8. `step` 和 `microbatch` 有什么区别？（step=一次参数更新；microbatch=显存不够时拆开算的子批，多个 microbatch 攒梯度才 1 个 step）

## 14. 一页总结（背这个）

```
训练 = 循环{ forward → loss → backward → update }

forward:  ŷ = 模型(x)              用当前参数算预测（= 一堆 GEMM）
loss:     L = (ŷ - y)²             一个数，衡量错多少
backward: 梯度 = 链式法则连乘       从 L 往回逐段乘局部导数（反向传播，= 又一堆 GEMM）
update:   参数 -= 学习率 × 梯度      朝梯度反方向下山

核心直觉:
  导数 = 局部斜率（山坡陡峭度）
  梯度 = 所有偏导打包，指向上升最快方向 → 减号朝反方向 = 下山
  链式法则 = 隔几步的总影响 = 沿路局部斜率连乘（齿轮传动）
  反向传播 = 系统地从后往前跑链式法则

CUDA 连接:
  前向 GEMM + 反向 GEMM（≈2×算力）+ 逐元素（激活）+ reduction（loss）
  训练显存 ≈ 推理×N（还要存梯度 + 优化器状态）
```
