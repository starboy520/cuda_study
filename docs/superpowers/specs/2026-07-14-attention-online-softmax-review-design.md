# Attention 与 Online Softmax 复习文档扩充设计

## 1. 目标

扩充现有 `docs/proofs/Online_Softmax正确性证明.md`，使其既保留严格数学证明，又能作为自包含的复习文档，重点解决 `O_acc` 难以形成直觉的问题，并连接当前 M1 `Br=4` Query-Tiled Attention 学习阶段。

完成后，读者应能从标准 Attention 公式出发，依次解释：

1. `l` 为什么是 softmax 的标量分母；
2. `O_acc` 为什么是未归一化的向量分子；
3. 为什么最终输出为 `O=O_acc/l`；
4. 新最大值出现时，为什么 `l` 与 `O_acc` 必须同时乘 `alpha`；
5. 元素级、tile 级和 `Br=4` 多 query 场景为什么都遵守同一换基准公式。

## 2. 文档定位

直接更新现有证明文档，不创建重复的入门文档。组织方式由“先给抽象证明”调整为“直觉 → 公式 → 手算 → 证明 → M1 应用”。

原有换基准引理、分块合并、结合律、流式正确性、causal 和浮点说明全部保留；允许调整章节顺序并消除重复表述。

## 3. 内容结构

### 3.1 复习入口

- 写出单 batch、单 head 的标准 Attention 公式和各张量 shape；
- 单独展开某一条 query 的行公式；
- 将 Attention 输出改写为加权平均的“向量分子除以标量分母”；
- 用表格区分 `m`、`l`、`alpha`、`O_acc` 和最终 `O`。

### 3.2 Stable 与 Online 状态

- 解释减最大值不改变 softmax；
- 给出已处理集合 `S` 上的 `m(S)`、`l(S)`、`O_acc(S)` 不变量；
- 明确 `l` 与 `O_acc` 使用同一个指数基准 `m`。

### 3.3 换基准与更新公式

- 严格证明换基准恒等式；
- 推导元素级流式更新；
- 推导 tile 级更新；
- 显式说明只缩放 `l` 而不缩放 `O_acc` 会让分子、分母处于不同尺度。

### 3.4 数字手算

使用少量 score 和二维 `V`，完整展示：

- 第一块建立 `m/l/O_acc`；
- 第二块产生更大最大值；
- 旧 `l` 和旧 `O_acc` 同乘 `alpha`；
- 最终 `O_acc/l` 与一次性标准 Attention 对齐。

数字例子优先沿用现有教材中的 `scores=[2,1,4,3]`，避免不同文档使用过多例子。

### 3.5 严格正确性证明

- 保留分块状态合并定理；
- 保留交换律与结合律证明；
- 保留流式归纳证明；
- 将 `(m,l,O_acc)` 作为完整 Attention 状态统一证明；
- 明确实数下 exact、浮点下只因运算顺序产生舍入差异。

### 3.6 边界与 M1 连接

- 解释 causal mask 中 `-∞` 的零贡献；
- 规定局部全 mask 时保持旧状态，避免 `-∞-(-∞)`；
- 推广到 `Br=4`：`m/l/alpha` 为 `[Br]`，`O_acc` 为 `[Br,D]`；
- 强调 K/V tile 可以共享，但四条 query 的 softmax 状态不能共享；
- 给出常见错误表和闭卷自测题。

## 4. 表达原则

- 使用中文讲解，保留 Attention、Online Softmax、tile 等英文术语；
- 先给一句话直觉，再给公式和证明；
- `O_acc` 始终表示未归一化向量分子，不与“已除以旧 `l` 的输出状态”混用；
- 公式统一使用 `O_acc`，避免用 `O` 同时指累加器和最终输出；
- 不加入完整 CUDA kernel，保持证明与复习文档定位；
- 与 M1 文档中的 `Br=4`、`Bc=16`、逐行状态定义保持一致。

4. 元素级、tile 级和 `Br=4` 更新使用一致符号；
5. 原证明中的分块、结合律、causal 与浮点结论没有丢失；
